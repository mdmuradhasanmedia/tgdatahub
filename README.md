# TGDataHub

TGDataHub is a lightweight, PHP-based collection of online tools and utilities. It provides a modern, responsive interface with dozens of useful web tools for file conversion, image processing, generators, calculators, downloaders, developer utilities, and more.

## ✨ Features

* 40+ useful online tools
* Responsive and mobile-friendly UI
* Pure PHP architecture
* Shared layout using reusable partials
* Server-side APIs for supported tools
* SEO-friendly structure
* Easy to extend with new tools
* Lightweight and fast

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/mdmuradhasanmedia/tgdatahub.git
```

Move the project into your web server directory.

Example:

```
htdocs/
public_html/
www/
```

Then visit:

```
http://localhost/
```

or

```
https://yourdomain.com/
```

---

## 🛠 Requirements

* PHP 8.0 or newer
* Apache / Nginx
* mod_rewrite (recommended)
* File upload enabled
* GD Extension
* Zip Extension
* cURL Extension
* OpenSSL Extension

Some tools may require additional PHP extensions depending on their functionality.
